简介Overview

飞机上的起动/发电机在发动机启动时作为电动机工作，启动完成后转为发电机为机上设备供电。这个项目在 Simulink 中搭建整套系统模型，网侧采用三相两电平六开关有源前端（AFE）变流器。An aircraft starter/generator runs as a motor to start the engine, then switches to generating power for on-board systems. This project builds the full system model in Simulink, with a three-phase two-level six-switch active front end (AFE) converter on the grid side.
