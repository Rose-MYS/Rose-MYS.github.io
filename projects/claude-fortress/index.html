    是什么What it is

    让 AI Agent 帮你在电脑上干活很方便，但它能联网、能跑命令，一旦出错影响的是整台机器。Claude 堡垒把我自己搭隔离环境的经验整理成一套开源 Agent Skill：装好之后，Agent 会按规范一步步带你把它自己关进隔离环境，每一步先说清风险等级，高风险操作必须你本人确认。Letting an AI agent work on your computer is handy, but it can reach the network and run commands, so a mistake affects the whole machine. Claude Fortress turns my own isolation setup into an open-source Agent Skill: once installed, the agent walks you through sandboxing itself step by step, states the risk tier of each step, and needs your explicit approval for anything high-risk.

    三档风险，按步走Three risk tiers, one step at a time

    • A 档 · 纯只读：离线盘点机器配置，不写文件、不联网、不改网卡。Tier A · read-only: an offline inventory of the machine — no writes, no network, no adapter changes.
    • B 档 · 可逆：中性的功能探测，随时能撤回。Tier B · reversible: neutral functional probes that can be undone.
    • C 档 · 高风险：改网关规则、可能断网的动作，必须你本人逐项确认。Tier C · high-risk: gateway rules and anything that might cut the network — each needs your own sign-off.

    几条路线Routes

    • 虚拟机堡垒：Windows 虚拟机只接一个隔离网段，出口经过一台默认拒绝的 OpenWrt 网关，客机再加一层防火墙白名单。VM fortress: a Windows VM on a single isolated network, egress through a default-deny OpenWrt gateway, plus a firewall allow-list inside the guest.
    • 本机轻量：不开虚拟机，用独立浏览器配置和命令行做应用层隔离。Lightweight local: no VM; app-level isolation with separate browser profiles and the CLI.
    • 远程开发机：把 Agent 放在一台 Linux 服务器上，本机只连终端。Remote dev box: run the agent on a Linux server and only connect a terminal locally.
    • 可选进阶：多 Agent 协作：共享协作区、两层 Git、交接文档制度，和账号、网络无关，可以单独用。Optional: multi-agent workflow: a shared workspace, two-level Git and handoff documents — independent of accounts or networking.

    先自检，再上线Self-test before going live

    它不是"装了就安全"的黑盒。每台机器的系统、网卡和固件都不同，所以 Skill 会陪你在自己的机器上做四类实测：冷启动时网关默认不放行、重启或重载规则后边界依然闭合、主动断开上游时客机彻底断网不回退直连、DNS / IPv6 / UDP / WebRTC 没有泄漏。It is not a black box that makes you safe on install. Every machine differs, so the Skill has you run four checks on your own hardware: the gateway forwards nothing on a cold boot, the boundary stays closed after restarts and rule reloads, the guest goes fully offline (no fallback) when upstream is cut, and DNS / IPv6 / UDP / WebRTC do not leak.

    多个 Agent 协作完成：经过两轮独立红队审阅并修复全部高优先级问题；仓库只放脱敏后的模板和文档，不含任何真实配置或账号信息。Built with several agents and two rounds of independent red-team review, with every high-priority issue fixed; the repo holds only sanitised templates and docs, with no real configs or account data.
