郝哥快跑Run Haoge Run

一款 3D 三车道追逃游戏：郝哥从菜市场一路跑过老街和后巷，完成每一段的目标、抵达出口。躲障碍、收西瓜，用「保熟」技能甩开追兵。A 3D three-lane chase game: Haoge runs from the market through an old street and a back alley, clearing each segment’s goal to reach the exit. Dodge obstacles, grab watermelons and use the “Baoshu” skill to shake off the chaser.

    操作Controls

    • 换道：← → 或 A / D（手机左右滑）Change lane: ← → or A / D (swipe on mobile)
    • 转弯：绿灯亮时按 ← 或 → 确认（手机上有专门的按钮）Turn: press ← or → on a green light (dedicated buttons on mobile)
    • 跳跃 / 二段跳：↑ 或 W（上滑）Jump / double jump: ↑ or W (swipe up)
    • 滑铲 / 快速落地：↓ 或 S（下滑）Slide / fast drop: ↓ or S (swipe down)
    • 「保熟」技能：E；暂停：空格 / Esc / P；静音：M“Baoshu” skill: E · Pause: Space / Esc / P · Mute: M
