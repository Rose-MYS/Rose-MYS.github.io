郝哥快跑Run Haoge Run

一款可离线游玩的 3D 三车道无尽跑酷：躲障碍、收西瓜，用「保熟」技能拉开和追兵的距离，还藏着彩蛋。An offline 3D three-lane endless runner: dodge obstacles, collect watermelons, and use the “Baoshu” skill to escape the chaser. Easter eggs included.

操作Controls

  • 换道：← → 或 A / D（手机左右滑）Change lane: ← → or A / D (swipe on mobile)
  • 跳跃 / 二段跳：↑ 或 W（上滑）Jump / double jump: ↑ or W (swipe up)
  • 滑铲 / 快速落地：↓ 或 S（下滑）Slide / fast drop: ↓ or S (swipe down)
  • 「保熟」技能：E；暂停：空格 / Esc / P；静音：M“Baoshu” skill: E · Pause: Space / Esc / P · Mute: M

网站上的版本使用程序化生成的角色和合成音效。The version on this site uses procedurally generated characters and synthesised sound effects.
