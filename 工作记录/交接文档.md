## 怎么运行 / 复现

- 重新生成页面：在仓库根目录运行 `python 工作文件/generator/gen.py`（只用标准库；输出到仓库根目录，也可用环境变量 `SITE_ROOT` 指定）
- 本地预览：直接双击 `index.html`
- 发布：推送到 GitHub 仓库 `Rose-MYS.github.io`，几分钟后生效

## 待办与未决

## 注意事项

- GoatCounter 统计覆盖首页、关于、项目介绍及文章。生成页面的统计标签由 `gen.py` 输出，手写文章页面保留同一个标签。形声试玩页也纳入统计。更新试玩时，复制 ShapeSound 的 build.py --pages 生成的 docs/index.html。

- ⚠️ **首页 / 关于 / 项目目录 / 项目详情页是生成出来的**：要改这些页面（包括导航、Elsewhere、开源贡献小节），请改 `工作文件/generator/` 里的脚本再重新生成；直接改 HTML 会在下次生成时被覆盖。之前 Writing 导航两次丢失、开源贡献小节丢失，都是因为别的 agent 手改了 HTML，而另一个 agent 用生成器重新生成时把手改的内容覆盖了（2026-11-27 已把这些手改内容全部并入生成器）。`writing/` 下的文章页仍是手写，生成器不会碰。
- 每段文字写两遍：`<span class="zh">中文</span><span class="en">English</span>`，改时两种语言一起改
- ⚠️ **改全站页面头部（导航、资源版本号）时，以仓库里当前文件为准逐个修改，不要用旧模板整段覆盖**：2026-11-26 22:36 的提交 1b39cb4 用旧头部覆盖了 10 个页面，把导航里的 Writing 弄丢了，11-27 才发现并修复。改完用脚本核对每个页面的导航都含 Home / About / Projects / Writing 四项。
- 改了 `assets/style.css` 或 `site.js` 后，要把全站所有页面引用的 `?v=` 版本号一起升，否则浏览器会用缓存的旧文件
- `参考资料/`（扒谱、seu_race1 的本地副本）只做参考，已被 `.gitignore` 排除，不会上线
- 推送前确认用户同意（推送即上线）
- 第三方素材（钢琴采样等）要在 About 页保留署名
